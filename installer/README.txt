无线设备电量监视器 CN（Wireless-Device-Battery-Monitor-CN）
============================================================

把无线鼠标、耳机、键盘和手柄的电量显示在 Windows 任务栏上，是上游项目
Wireless Battery 的简体中文本地化版本。

快速上手
--------
1. 双击程序启动后，任务栏（时钟左侧）会出现设备图标和电量百分比；也可以
   在托盘图标上右键 → “以托盘图标显示”切换成托盘模式。
2. 右键菜单可以：逐个显示/隐藏设备、立即刷新、开机启动、切换语言，
   以及选择挂件显示在哪块显示器上。
3. 电量 ≤15% 时图标变红；充电时显示蓝色闪电；设备休眠时变暗并保留上次电量。
4. 连接了多个设备时，挂件默认只显示一个：鼠标指向挂件，滚轮向上/向下切换设备，
   切换时带滑动动画（不想这样可在右键菜单里关掉“一次只显示一个设备”）。
5. 部分耳机需要随附的 headsetcontrol.exe，请保持它与主程序放在同一目录。

语言
----
默认界面为简体中文。右上角菜单“语言”里可以切回英文或其他语言，也可以在
%APPDATA%\WirelessBattery\lang 放入自己的 .txt 词条文件来新增语言。

卸载
----
设置 → 应用 → 已安装的应用 → “无线设备电量监视器 CN” → 卸载，
或运行安装目录下的 Uninstall.exe。卸载会同时清除开机启动项和本程序的设置。
